# v2.3 UI presentation update

The playable showcase HUD uses Simplified Chinese by default and exposes a visible `L / ENGLISH` switch in the upper navigation rail. The same switch is available through the `L` key while a modal is open. Switching to English changes the labels used in the arena, objective rail, operator/companion cards, stage timeline and modal headings; switching back returns to Chinese immediately. The presentation does not describe the project as a portfolio for a particular design discipline.

Normal sessions load and save the language preference in `AegisUI.ini` under Unreal's `GeneratedConfigDir`. Missing or invalid preferences fall back to Chinese. Automated captures and probes use an isolated Chinese starting state and do not write to the user's preference file. Language changes remain separate from combat, AI, navigation and economy; the setting affects presentation only. A brief confirmation or save-failure message appears beneath the language switch while a modal is open.

The v2.3 visual pass keeps the existing dark teal / paper card system, but gives the language control its own stable navigation slot beside the menu. Chinese is the first frame of a fresh installation and the reproducible capture path; normal sessions restore the user's last choice.

Chinese mission, upgrade, pause and result copy wraps between characters even when the sentence contains spaces, numbers or Latin key names. Latin words stay together, and closing Chinese punctuation stays with the preceding character. This fixes mixed copy such as `Q 保留伤害` without adding spaces between Chinese glyphs. Result reasons, metrics, route hints, overclock status and pause controls use the same language preference.

The event rail translates initial instructions as well as shot, repair, pulse, overclock, route and reward feedback, including energy and health units. Companion tactical states such as Guard, Focus and Rally are mapped at the HUD presentation layer; an unknown state displays the known current command in Chinese rather than exposing an untranslated internal name. The underlying DebugState and telemetry remain unchanged. Diagnostics headings, perception flags, guard-position explanations and resource transactions also follow the selected language.

The language control is painted after the modal dimmer, so it stays clearly visible on briefing, pause, upgrade and result screens. Buttons size their labels to the available width and retain consistent inner margins. Health values align to the card's right edge, and upgrade descriptions leave a clear gap above the install action. The initial language checkpoint compiled and passed seven Core automation tests; the combined gameplay build subsequently passed eight Core tests. The new packaged native capture at `D:/AegisWork/Reports/v23-native-final-20260922` contains 3116 full-resolution frames and the actual language switch. Chinese and English briefing, HUD, scan feedback, upgrades and result frames were reviewed. Persistence is covered by the disk round-trip Core tests; capture sessions deliberately do not save user preferences.

The two real archive caches replace the former decorative survey minimap marker. Their world coordinates and claimed state come from the gameplay actor. A compact `S1` / `S2` map display tracks them, while a contextual `G` / `H` scan card replaces the lower-left ability card within five metres of an unclaimed cache. The card explains the 1.8-metre interaction range, 2.5-second hold, interruption conditions and current reward choice. Supply restores up to 20 player / 15 nearby ally health; a relay key boosts a data relay to x1.25 and never boosts extraction. The result screen adds archive count, reward counts and actual cache healing. Feedback is translated at display time, so switching language updates scan messages immediately.

The ordinary lower-left ability panel is reduced from 127 to 100 design pixels high. The scan card uses that existing area, and the world marker is limited to a nearby unclaimed archive, keeping the central aiming area open. Briefing and pause instructions explain the new inputs in both languages. The fresh native film and final decoded QA are documented separately in [the v2.3 delivery record](portfolio-v2.3-delivery.md).
