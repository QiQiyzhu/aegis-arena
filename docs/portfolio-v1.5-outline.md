# Aegis Arena v1.5｜系统／综合策划证据提纲

**定位：** 用一个可操作的小型战术循环，证明目标拆解、资源取舍、成长反馈与迭代能力；战斗、关卡和视觉表现共同支撑。只填写实际完成内容与本人可解释的贡献，不虚构游戏经历、时长或获奖。

**设计说明 PDF 建议结构：** ①目标体验与贡献范围；②“准备→争夺目标→升级选择→下一阶段→结算”循环及状态图；③生命／能量／冷却／时间／升级机会的取舍表；④真实画面中的信息层级与反馈规范；⑤一个问题的前后改动、验证及遗留限制。参考依据见 [获奖参考](portfolio-v1.5-references.md)，开发版本和证据版本须一致。

| 视频时间（建议约 3 分钟） | 要证明什么 | 必须出现的实机证据 |
|---|---|---|
| 0:00–0:15 | 核心目标与作品定位 | 新画面、角色、当前目标；一句说明本人工作。 |
| 0:15–0:55 | 资源与行动取舍 | 一段连续目标争夺；预警、位移、冷却或生命变化。 |
| 0:55–1:30 | 成长选择影响后续操作 | 升级卡理由→确认→实际效果，不能只拍菜单。 |
| 1:30–2:10 | 阶段目标形成完整循环 | 新阶段条件、完成／失败反馈与结算。剪辑切换明确标注。 |
| 2:10–2:45 | 能发现并修正设计问题 | 一个真实前后对照、检验方式及负面结果／限制。 |
| 2:45–3:00 | 可交付与可追问 | 版本、操作入口、职责及素材来源。 |

**证据附件：** MP4 ≤300 MB；PDF 直接附件上传，不以网盘链接替代。保留原录屏和对应构建记录供复查。字幕必须在实际导出分辨率可读，导出后检查完整播放、音量、时长与字节大小。

**完成判据：** 观众能指出目标、一个有代价的选择、该选择的真实后果和一次迭代依据。新功能／新画面只引用本版实测；v1.4 的 36 局与旧 0/30 标注历史版本，不能移作 v1.5 效果。未验证的可读性或平衡性只写设计假设，不写“玩家已证明更好”。
