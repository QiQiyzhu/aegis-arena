## 启动 v1.3

Development / Shipping 的目录与状态集中列在 [v1.3 包入口](../docs/upgrade-v4.md#启动与操作)。保留完整的 `Windows` 文件夹，并安装 **Python 3.10+ 与 Tkinter**。第一次运行先双击包内 **Configure Aegis AI.cmd** 保存配置，再双击 **Play Aegis Copilot.cmd**；已有配置可直接启动。旧 v1.2 包与公开 v1.0 下载不包含 Copilot。

本机已保存配置，可直接启动 [Play Aegis Copilot.cmd](<D:/AegisWork/Packages/copilot-v1.3-development/package/Windows/Play Aegis Copilot.cmd>)。两个新包均构建完成；Development 包实际通过 30 项输入/退出与 13 项云端 Copilot 检查，Shipping 17 项开发标记检查通过。[最终验收及原件](../evidence/upgrade-v4/acceptance.json)。

默认云端配置为 **DeepSeek / deepseek-flash**，端点 `https://api.deepseek.com/chat/completions`。在配置窗口输入自己的 API Key：**Save settings 只保存，Test connection 才会发送一次小请求**。密钥用当前 Windows 用户的 DPAPI 加密，启动器通过子进程环境传入游戏。连接成功不等于计划效果通过。语言请求需要网络与用户账户；服务不可用时保留规则 AI 和手动控制。**本版不捆绑本地模型**，本地 Qwen 是保留负结果的实验选项。

**1/2** 选难度，**Enter** 部署；**WASD** 移动、鼠标瞄准、按住左键射击、右键近战、**Space** 闪避、**Q** 脉冲。**Tab** 打开暂停的目标面板，Enter 提交，Tab/Esc 返回；战斗中 **Z/X/C** 保护、集火、集合，并取消旧计划。**R** 重开。**Esc/P** 打开可点击菜单，选择 Quit to desktop 或按菜单中的 **X** 退出；Copilot 打开时先 Esc 关闭面板，再 Esc 打开菜单。原有三阶段目标、升级和敌人战术详见 [v1.2 Uplink](../docs/upgrade-v3.md)。

计划记录位于 `Saved/AegisPlans`，展示请求、实际采用的技能和完成/失败/取消结果。模型短标签是任务摘要，不是隐藏思维链；这里没有在线训练、RAG 或自我学习声明。

本轮已通过 **381 条可移植 C++ 断言、117 项 Python 测试、6 项 UE Core 测试（含 20 条模型协议断言）**，以及五组既有战斗回归。云端十二条合成观测语义案例三层检查均为 12/12；真实 UE 云端探针为 13 项，五类替代 HTTP 故障为 25 项。**云端游戏探针只验证 `capture_relay > guard` 计划和队友移动，执行两秒后手动取消，没有证明完整占点及后续 Guard 自动完成。** 各批次、最终 UI 改动与原始记录见 [验证记录](../docs/upgrade-v4.md#验证记录)。合成输入不能替代真人体验。

## 构建与复查

可移植层要求 Python 3.10+ 和 C++17 编译器（`g++`、`clang++` 或 Zig），无需 API Key 或 Unreal。运行严格构建、当前核心断言、Python 测试和小样本 smoke：

```bash
python3 scripts/verify_portable.py --compiler g++
```

Windows 可运行 `python scripts/verify_portable.py --compiler '实际编译器绝对路径'`；编译器已在 PATH 时可省略该参数。新增模型接口测试使用假密钥与 HTTP 替身，Windows DPAPI 测试在非 Windows 平台跳过。输出进入新的 `outputs/` 目录；`--full` 增加历史 60 场评估。原生构建细节见 [Unreal 安装与验收](../docs/unreal-setup.md)。[可移植 CI](../.github/workflows/portable.yml) 不安装或执行 Unreal；本轮是否公开发布以新版验证记录为准。

Unreal 目标为 **UE 5.8.2** 与配套 MSVC / Windows SDK；Editor 构建还需要相应 .NET Framework SDK。仓库中的地图、BT/BB/EQS 和材质由实际 Editor 保存；`-GenerateAssets` 面向刻意不带资产的检出，拒绝覆盖已有地图。

```powershell
./scripts/build_unreal.ps1 -EngineRoot 'D:/Program Files/UE_5.8' -CacheRoot 'D:/AegisWork' -Automation
```

C++ 管理生命、伤害、观察边界、战术技能、模型协议与请求生命周期；资产管理 BT/EQS 图和场地配置。Copilot 选择高层任务，现有控制器执行动作；历史评估模式仍有独立的 priority/utility 路径。StateTree 和 Learning Agents 未启用，原因见 [RL 实验范围](../docs/rl-experiment.md)。
