# Aegis Arena v2.3 · 试玩说明

双击桌面 **Aegis Arena v2.3**，或完整 Windows 包内的 **PLAY-Aegis-v2.3.cmd**。无需 Unreal 编辑器。请保留整个包目录。

首次运行默认中文，按 **L** 或点击语言按钮切换 English；正常退出后会记住选择。按 **Enter** 开始，与队友完成固守中继、转移数据、清敌撤离三个阶段。每次阶段升级可选择一个尚未安装的能力。

| 操作 | 作用 |
|---|---|
| WASD / 鼠标 | 移动 / 瞄准 |
| 左键 / 按住右键后释放 | 射击 / 蓄能射击 |
| Space | 闪避 |
| Q / E / F | 脉冲 / 按实际治疗量修复 / 当前数据中继超频 |
| Z / X / C | 指挥队友防守 / 集火 / 集结 |
| H / 按住 G | 选择档案奖励 / 连续扫描 |
| V | 简报或第一次升级期间切换中继路线 |
| 1 / 2 / 3 | 选择阶段升级 |
| L / M | 切换语言 / 音乐开关 |
| Esc 或 P | 暂停菜单；菜单或结算页按 X 退出 |

地图的 **S1、S2** 是可选档案缓存。靠近至 1.8 米内，先按 H 选择补给或密钥，再按住 G 扫描 2.5 秒。受伤、离开范围或松键会清空进度，每处档案每局只能领取一次。

补给最多恢复自己 20 点和附近无遮挡队友 15 点生命，只按缺失生命治疗；无人需要治疗时不消耗档案。密钥会让下一座有效数据中继加速至 1.25 倍，不能用于撤离，也不能同时存两枚未使用密钥。

关注共享能量、敌人的争夺与队友位置。最后必须由玩家亲自进入撤离区。窗口默认 1600×900，音效与阶段音乐随游戏运行播放。
