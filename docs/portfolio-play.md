# Aegis Arena · PRISM RELAY 作品集版

双击桌面 **Aegis Arena 作品集**，或解压完整游戏包后双击 **PLAY-Aegis-Portfolio.cmd**。无需安装 Unreal 编辑器，无需 API Key。保持整个 Windows 文件夹完整；不要只复制一个 exe。

这是约两三分钟一局的协同战斗原型。玩家与一名 AI 队友完成三个目标：启动中继 → 两点顺序传输 → 清敌撤离。先用 Guided 档位熟悉规则，按 Enter 开始。

| 按键 | 作用 |
|---|---|
| WASD / 鼠标 | 移动 / 瞄准 |
| 左键长按 / 右键 | 连续射击 / 近战 |
| Space | 朝移动方向冲刺；没有无敌帧 |
| Q | 范围脉冲，消耗 35 能量，冷却 6 秒 |
| E | 修复自己及合格的近距离队友，消耗 40 能量，冷却 8 秒 |
| Z / X / C | 保护 / 集火鼠标附近可见敌人 / 在鼠标位置集结 |
| 1 / 2 / 3 | 局间选择升级 |
| Esc 或 P | 暂停菜单；菜单或结算页按 X 退出，也可点退出按钮 |
| R | 重开，清空本局升级和能量变化 |
| F1 | 显示或隐藏诊断；正式演示默认关闭 |

观察上方目标和场景中的亮色圈。只有友军在圈内且敌人没有争夺时，目标才推进；完成目标后还要清除本波敌人。第二阶段的两个目标有固定顺序。第三阶段必须玩家亲自进入撤离圈，队友不能代替撤离。

能量初始 60、上限 100；击杀 +12，阶段完成 +25，溢出不会保留。Q 与 E 使用同一个库存。没有任何合格治疗目标时 E 不扣费，Q 空放也会扣费。阶段间的恢复和治疗升级会影响是否需要再支付 E，试着比较不同选择。

三种升级中本局最多选两个：穿透弹让射线最多伤害两名敌人；救援脉冲让 Q 附带治疗；生命链接把实际友方伤害的 10% 转成双人治疗。它们不会跨局保留。

这是 Windows Development 演示包。新电脑若提示缺少 VC++ 运行库，可运行包内 Engine/Extras/Redist/en-us/vc_redist.x64.exe。没有开展手柄、键位重绑、中文输入法、所有硬件兼容性或真人平衡验证。

作品集模式使用已有战术 AI。F1 中的 Utility 分数与 EQS 标签会明确注明未控制本模式，不能当成大模型实时决策展示。历史云端 Copilot 与 v1.4 Decision Lab 入口独立保留。
