# Aegis Arena v3：获奖游戏参考与可玩性改进

本文保留研究阶段提案；实际交付功能、未采纳范围与验证以 [v1.2 Uplink](upgrade-v3.md) 为准。

研究日期：**2026-09-11**。起点是用户对 v1.1 试玩的反馈：玩法单一、队友作用弱、敌人缺少战术变化、退出入口不明显。本文记录设计参考和验收目标；不代表这些建议已经实现，也不把自动化通过解释为玩家觉得好玩。实现与验证进度应另行记录。

## 五项落地建议

以下均为本项目的设计判断和**待验证目标**。优先用当前场地、原始几何体、现有角色/战斗组件与 BT/EQS 完成闭环；不需要先加入联网、程序化关卡或学习型 AI。

### 1. 让队友的职责可控制、可观察

默认保持玩家侧后方的支援位置；提供“保护 / 集火指定目标 / 集合”三种明确指令，守点可作为保护模式的目标位置。指令立即给出短文字与地面标记，HUD 显示**正在执行的动作**，例如“移动到集合点”“射界被挡，正在换位”“支援冷却中”。指令失效或路径失败应有反馈和可预期的回退。恢复跟随时清除旧目标，集火不能变成越过掩体后无限追踪敌人。

这项建议来自 DRG 的有限助手职责和任务反馈。当前组件已有支援、移动、观察记忆等基础，重点是把它们组织成可靠行为。v1.1 的 HUD 按 `Decision->Selected` 显示意图，意图与任务实际执行可能不同；应以执行状态为准。玩家射线被队友身体遮挡时也要让队友换位。

**验收目标：** 玩家绕障碍、快速换向、指定隔墙目标、取消命令时，队友有可解释的结果；连续发两次不同指令不会执行旧指令；能真实观察到至少一次有效支援；状态文字与世界中的动作一致。集火指令只授予明确的目标信息，不授予持续穿墙位置更新。

### 2. 让敌人有不同战术，并给玩家反制窗口

用少量角色形成组合：压制者保持中距离并找射界；侧翼者争取不同角度而非排队追同一点；冲锋者先预告路线，随后沿已承诺方向突进。先用轮廓、角色名、预警形状区分，颜色只作辅助。攻击可以经过“准备 → 锁定方向/落点 → 执行 → 恢复”；预警时长须通过实际试玩调整，不能只闪一下就命中。

这是对 Into the Breach 信息可读性的实时改编，也是对 Hades 多种遭遇的有限规模借鉴。敌人可以利用观察到的位置和固定目标点行动，但不应靠提高命中率、持续获知玩家位置来表现“聪明”。空间协调比同时增加血量和伤害更有意义。

**验收目标：** 玩家能仅凭画面辨认至少两种不同威胁；离开已锁定范围可以避开攻击；进入掩体能中断合法射击；相同总敌人数下，改变角色组合会改变玩家移动或优先击杀顺序。死亡、暂停、失去合法目标和重开都应清除未完成攻击及预警。

### 3. 在局内加入改变打法的选择

利用现有波次间歇，提供三选一的行为升级，例如：穿透一个敌人的射击、冲刺终点的短程震荡、围绕队友的短时护盾。每个选项用一句话解释触发方式和限制，并让下一段战斗立即有机会用到。首轮可只做三项、每局一次选择，确保各项真的改变操作和取舍。升级选择期间暂停战斗计时，确认后进入下一段；不要让玩家在五秒自动倒计时内被迫读完并选择。

这项建议受 Hades 的能力组合与升级界面启发；上述具体能力是本作建议，不是对原作技能的复刻。

**验收目标：** 三个选项分别改变命中几何、冲刺时机或队友站位需求；仅改变数值不算通过。升级只应用一次，UI 文案与实际触发一致，重开后清空，未选时不得悄悄替玩家选择或进入下一波。

### 4. 让竞技场有清敌之外的目标

在同一场地串起一个小任务：“夺回中继 → 维持中继充能 → 到撤离点完成传输”。敌人威胁目标区域，使追击、守位、队友集火和离开危险区产生取舍。先选择一个可验证的目标规则，例如玩家在区域内且区域未被敌人占据时进度增长；离开或被争夺时暂停并显示原因。可选拾取能源只在第一版闭环稳定后增加，避免同时堆积过多新规则。

这是对 Into the Breach 保护关键建筑的目标冲突、DRG 合作任务职责的设计推断。v1.1 基线的纯三波清敌的胜利条件可保留为单独模式，新任务不能只有新名称而进度仍完全依赖击杀数。

**验收目标：** 不清光敌人也可能推进目标，但单纯站在角落射击不能自动完成任务；进入、离开、争夺、完成区域时进度与提示一致；队友死亡不会产生无法继续又无失败提示的状态；玩家无需阅读仓库文档就能说出当前目标与下一步。

### 5. 提供明显且完整的退出路径

常驻提示“Esc：菜单 / 退出”，Esc 打开包含“继续、重新开始、退出桌面”的菜单；鼠标与键盘都能选中并执行。退出与暂停恢复必须分清。若保留退出确认，就明确说明“结束本次挑战并退出到桌面”，允许 Esc 取消；菜单打开或关闭时清掉射击等持续输入，避免点菜单同时开枪。

这是对用户明确反馈的直接修复，不归因于上面任何奖项。Canvas HUD 可以先实现少量清楚、可操作的选项；采用 UMG 与否是实现选择，玩家关心的是入口、焦点与结果。

**验收目标：** 新玩家无需 Alt+F4 能找到并退出；在简报、战斗、暂停、胜负界面均有可用退出路径；取消后回到先前状态；确认后实际进程结束；菜单操作不会继续移动、伤害角色或意外重开。

## 如何判断这轮改进有效

先验收正确性，再观察玩家决策。现有核心测试、UE 世界测试和打包检查应继续覆盖重开、观察记忆、碰撞、冷却及人口回收；新功能还需对应命令、预警、目标和升级的运行时验证。

随后在实际独立包中做两次短局：第一次不提示操作，观察能否找到目标、给队友指令、识别危险、退出；第二次换一种升级或敌人组合，观察打法是否真的改变。记录失败原因与原始画面，而不把合成输入探针、静态截图或一次获胜当成“AI 更智能”“更有趣”的证据。首轮试玩目标是验证可理解性与战术差异，不作统计性玩家体验结论。
