# Aegis Arena v2.4 RC · 游玩说明

这是 Windows 64 位单人游戏的发布候选版，包含一个竞技场、三个阶段和两处可选档案。

1. 下载 Windows 游戏压缩包，**右键 → 全部解压**。
2. 进入解压后的文件夹，双击 **AegisArena.exe** 或 **PLAY-Aegis.cmd**。无需 Unreal 编辑器或额外启动参数。
3. 第一次游玩选择「引导」，按 **Enter** 开始。与队友固守中继、完成数据转移，最后亲自进入撤离区。

请保留完整文件夹，包括 `Engine` 和 `AegisArena` 子文件夹；不要只移动 EXE。如果系统提示缺少 Visual C++ 运行库，运行包内 `Engine/Extras/Redist/en-us/vc_redist.x64.exe` 后重试。

| 按键 | 作用 |
|---|---|
| WASD / 鼠标 | 移动 / 瞄准 |
| 左键 / 按住右键再松开 | 射击 / 蓄能射击 |
| Space | 闪避 |
| Q / E / F | 范围脉冲 / 修复自己与附近队友 / 中继超频 |
| Z / X / C | 队友防守 / 集火 / 集结 |
| H / 按住 G | 在档案旁选择补给或密钥 / 扫描 2.5 秒 |
| 1 / 2 / 3 | 选择阶段升级 |
| Esc / P | 暂停或继续；菜单也可鼠标操作 |
| R | 重新开始；进行中的行动会先要求确认，再按 R 确认或 Esc 取消 |
| L / M / F11 | 切换中英文 / 音乐开关 / 窗口与无边框全屏 |
| X（暂停或结算页） | 退出到桌面 |

切出游戏窗口会自动暂停；切回来后按 **Esc** 继续，避免突然恢复战斗。语言、音乐与显示模式会保存在本机，下次运行继续使用。默认窗口为 1600×900、60 FPS 上限；F11 可适应屏幕。

先学会 **移动 → 射击 → 站在中继圆环里** 即可开始。共享能量有限，Q/E/F 按需使用。S1、S2 档案可选：靠近后按 H 选择奖励，再按住 G；受伤、离开或松键会打断。补给恢复缺失生命，密钥加快下一座有效数据中继。每处每局只能领取一次。

本版没有联网、账号注册或付费功能；不要求 API 密钥。它仍是小型完整流程原型，尚未完成商店上架审核或多人硬件兼容测试。
