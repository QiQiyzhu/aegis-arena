# Aegis Arena 决策演示：亲自操作

桌面入口为 **Aegis Arena 决策演示**。它直接启动独立 Unreal 游戏，不需要打开项目、编辑器或配置 API Key。发行包中的 `PLAY-Aegis-Decision-Lab.cmd` 是相同入口；请保留整个 Windows 文件夹，不能只复制 exe。

## 第一局

1. 启动后按 **Enter**。你控制青色角色，绿色角色是 AI 队友，橙色角色是敌人。
2. **WASD** 移动，鼠标瞄准，**按住鼠标左键**射击，**空格**冲刺。借助场景中的障碍物躲避攻击。
3. 目标是玩家存活，并在 **60 秒内消灭 2 名敌人**。玩家阵亡即失败；还有敌人而时间耗尽则超时。
4. **Esc / P** 打开暂停菜单；菜单里按 **X** 或点击退出按钮可退出到桌面。
5. **R** 返回准备界面并重置同一个种子；再按 Enter 开始。准备界面按 **1 / 2 / 3** 分别选择 Baseline / Improved / Priority。

普通演示保持 F1 关闭。底部会显示队友近期真实接受的动作和实际恢复的生命值。想解释决策时按 **F1**；可以先按 Esc 暂停，再阅读右侧快照。

## 怎样观察四种行为

| 行为 | 可以尝试的操作 | 需要核对的证据 |
|---|---|---|
| Follow 跟随 | 与队友拉开距离，绕过障碍物或走出它的视线 | 实际 BT 叶为 Follow；Improved 可显示 `position link` 来源。 |
| Attack 攻击 | 接近敌人，让队友看见威胁 | Sight 为 yes、攻击分数及实际 Attack/Chase，结合弹道和真实伤害。 |
| Support 支援 | 玩家受伤后接近队友，并利用掩体减少威胁 | Support 是否胜出、是否已接近，以及实际恢复量；高分或任务接受不等于已经治疗。 |
| Retreat 撤退 | 观察受到持续攻击、血量下降的队友 | Retreat 意图、真实 BT 叶、EQS 查询结果和接受的目的地。到点不等于已经脱离危险。 |

这些是由当前观察和竞争分数决定的行为，不是按一个键就强制播放的动画。某一局没有出现所有动作是正常现象。

## F1 面板怎么读

从上到下读：观察编号与年龄 → 自身血量、可见队友信息、位置链接 → 敌人 Sight/Memory → 四个候选分数 → 选择与切换理由 → 行为树最近尝试及是否接受 → EQS 请求、结果与目的地。

- `ally sight unknown` 表示没有当前视觉中的队友健康信息；Improved 可能仍有独立的、明确登记的队内**位置**链接。
- 敌人不可见时，当前距离显示 unknown；历史记忆不会变成对隐藏敌人的实时追踪。
- `selected` 是策略意图。`last ... failed` 是实际执行失败，不能当作成功动作；`accepted ... ago` 有独立的历史年龄。
- EQS 查询异步完成，面板显示查询 ID 与来源观察编号；未保留候选数据时明确显示 `not retained`。结果接受不代表已经到达。
- Priority 的分数仅作为参考，实际选择是“看到敌人则 Attack，否则 Follow”。

## 这次比较改变了什么

Baseline 使用原先的四项 Utility 和切换裕量。Improved 保留相同评分、BT、EQS、治疗和战斗参数，只在 Follow 丢失视觉队友时允许使用已登记的同队位置链接。链接不提供玩家健康或敌方数据，敌人控制器不能使用。

手动重复同一个种子可以比较体验，但你的操作和引擎调度仍会改变轨迹。正式报告使用固定的脚本玩家、独立的布局与种子；它不代表真人胜率，也不使用 portable 模拟结果替代 Unreal。此项目没有进行 RL 训练。
