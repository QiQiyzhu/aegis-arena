# Aegis Arena · 三分钟上手

**[下载游戏 ZIP](https://github.com/QiQiyzhu/aegis-arena/releases/tag/v2.5.0-rc.1)** → **全部解压缩** → 双击 **PLAY-Aegis.cmd** → 按 **Enter**。

请保留 `AegisArena`、`Engine` 文件夹和启动程序，不能只复制一个 EXE。无需安装编辑器或配置 AI 服务。

## 第一局要做什么

与队友完成三阶段任务：夺回当前数据中继、转移至下一处、清敌撤离。跟随屏幕目标和地面路线，在两次阶段间选择升级。最后需要玩家进入撤离区。

| 操作 | 按键 |
|---|---|
| 移动 / 瞄准 | WASD / 鼠标 |
| 射击 | 鼠标左键 |
| 蓄能弹 | 按住鼠标右键约 0.7 秒后释放 |
| 闪避 | Space |
| 脉冲 / 修复 / 中继超频 | Q / E / F |
| 队友防守 / 集火 / 集结 | Z / X / C |
| 切换中继路线 | 简报或第一次升级时按 V |
| 选择升级 | 1 / 2 / 3 |
| 语言 / 音乐 | L / M |
| 窗口 / 无边框全屏 | F11 |
| 精简装饰特效 | K |
| 暂停菜单 | Esc / P |
| 退出桌面 | 暂停菜单或结算页按 X |

蓄能弹、脉冲、修复和超频共用能量，不必一直用完。E 只按实际治疗量消耗；F 只用于前两阶段当前有效的中继。

## 可选探索

地图上的 S1、S2 是档案缓存。靠近后按 H 选补给或中继密钥，再按住 G 连续扫描 2.5 秒。松键、离开范围或受伤会打断扫描。

补给治疗自己及附近符合条件的队友；密钥加速下一座有效中继。每处每局只能领取一次，不需要清空档案才能通关。

## 保存与退出

语言、音乐、特效和窗口偏好保存在本机。当前任务进度没有中途续关功能；重开或退出会结束当前局。切换到其他窗口会自动暂停，回来后自行继续。

## 常见问题

- **打不开**：确认已经完整解压，没有只运行 ZIP 里的 EXE。检查下载页标明的版本与 SHA-256。
- **提示缺运行库**：运行包内 `Engine/Extras/Redist/en-us/vc_redist.x64.exe`，然后再次启动。
- **卡顿或窗口不适合**：先使用默认启动器；关闭其他高负载程序，按 K 开启精简特效，在菜单调整窗口模式。
- **不能修复或超频**：检查共享能量、实际缺失生命和当前任务阶段；这些技能并非任何时候都生效。
- **想重开**：按 R 后按界面提示确认；不要重复按移动或射击键代替确认。
