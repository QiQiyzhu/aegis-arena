# Aegis Arena v2.2 展示方向参考

本页只记录公开成品的展示原则，不复制角色、美术、音频或关卡内容。Aegis Arena 仍是原创的科幻中继争夺战斗 Demo。

## 公开参考

- [Infold Games：Ballad of Antara](https://www.infoldgames.com/en/news/5) 将队伍角色切换、动作战斗与探索空间放在同一个体验框架中。对本项目的推导是：演示先交代目标，再让移动、队友指令和射击反馈服务同一个关卡目的。
- [Infold Games：Infinity Nikki](https://infinitynikki.infoldgames.com/en/news/148) 介绍开放世界探索、平台移动和能力驱动体验。对本项目的推导是：把可读的阶段目标、路线选择和能力代价放进画面旁注，让观众能看懂玩家为什么移动和消费资源。

## v2.2 展示取舍

1. 先给出中继目标和撤离条件，再进入战斗；每段旁注只保留一个规则重点。
2. 让蓄能、超频、射击命中和击破反馈形成连续动作链，旁注解释代价，不叠加大段说明。
3. 用阶段切换、升级卡和结算页证明关卡闭环；跳过调试面板和冗长跑图，保留真实时间顺序的实机节选。
4. 采用更大的游戏画面和窄侧栏，强化角色轮廓、预警圈、目标环与资源 HUD 的视觉层级。

这些是展示编排建议，不是玩家研究结论，也不等同于参考作品的品质或系统实现。
