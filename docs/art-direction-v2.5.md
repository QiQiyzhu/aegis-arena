# Aegis Arena 2.5 · 战术美术设计与实施

这一轮保留科幻小队与晶体设施的既有世界，把简报、作战 HUD、技能反馈和复盘整理成一套可操作的战术终端。它是现有三阶段单人游戏的视觉升级，并不代表新增大型战役或完成商业发行认证。

## 决策与画面规则

| 玩家需要判断什么 | 本版表达 |
|---|---|
| 下一步去哪里 | 上方一条行动指令，紧邻倒计时和中继进度；任务图只显示公开节点与己方，不显示隐藏敌人 |
| 我与队友是谁 | 青色菱形标识行动员；薄荷绿护卫形与十字标识队友/修复 |
| 哪里危险 | 暖橙/红色敌人角色、方向尖角和攻击前摇提示；不与紫色档案共用主色 |
| 能否使用技能 | 底部共享储备 + 四个技能槽；费用、就绪、冷却、能量不足、无需治疗和中继限制用文字说明 |
| 档案是否值得停留 | 紫色分段六边形、距离、奖励选择、扫描进度与中断条件 |
| 暂停后如何继续 | 明确的继续按钮和按键；切出窗口仍暂停，返回后由玩家恢复 |

深蓝背景、钢蓝卡片、斜切角、细线和大块留白贯穿简报、暂停、升级与结算。简报中的幻想城堡插画改为由实际中继、档案和撤离位置绘制的任务节点图。底层场景和既有晶体资产保留，新的界面图形由 Canvas 直接绘制。

简报先讲三个行动步骤，再提供难度与开始操作。升级页用相同结构比较三项永久效果，并明确已安装状态。结算保留实际完成阶段、耗时、档案、伤害、消耗能量和真实治疗统计。基础 1280×720 排版中的文字最小逻辑高度为 16；宽度不足时截断次要状态，不把它缩成极小字号。

## 特效节奏与预算

蓄力环随真实蓄力比例从 108 收束到 64 世界单位，并逐段点亮；达到阈值后界面提示松开。释放加入短促径向闪片，0.32 秒衰减。闪避使用与移动方向一致的短线残影，0.30–0.42 秒消失。修复使用薄荷绿外扩/上升脉冲，0.68 秒衰减；超频、档案领取和中继完成使用各自语义色，最长 0.85 秒。既有真实命中弹道、撞击与敌人前摇继续使用实际战斗结果驱动。

新的 `AAegisTacticalFX` 使用 7 个固定组件：4 个颜色通道各 48 个短时装饰实例，共 192；另有行动员 4、队友 4、蓄力 24，共 32 个语义实例。事件不创建新组件或计时器，通道满时丢弃新装饰，旧装饰按寿命消退。该演员不写伤害、生命、能量、碰撞或导航状态。

按 **K** 或点击菜单中的特效按钮切换精简模式，偏好保存到本地。新脉冲从标准 30 个（中继完成 40 个）实例降至 8，闪避从 9 降至 3；既有枪击装饰可用槽由 24 降至 6。弹道、危险边界、蓄力比例、扫描进度、冷却和费用仍保留。精简模式限制装饰密度，并不等同于对所有视觉敏感性进行医学或无障碍认证。

## 验证与截图来源

所有展示游戏画面的 PNG 均为 Unreal Engine 5.8.2 / D3D11 的真实渲染，未使用生成式图片冒充游戏画面。前后简报对比使用相同 1600×900 分辨率和同类菜单夹具。编辑器 `-game` 截图与 Shipping 窗口检查分开记录。

发布流程夹具检查启动、语言/音乐、开始、失焦暂停回调、恢复和重新开始确认。艺术夹具额外检查固定组件池、真实模拟按键驱动的蓄力/释放/闪避、精简模式的语义保留、装饰衰减和容量压力。艺术夹具冻结 AI；修复对比直接触发展示 cue，不施加治疗。两张蓄力截图采样时刻不同，不宣称为逐帧同状态对比。

完整流程录制使用既有模拟输入驱动器，经过真实战斗、升级、档案、撤离与退出，不使用伤害或传送夹具。它用于流程和账本一致性检查，不能代替人类试玩或证明一般胜率。旧技能夹具需要第二次 R 按键来匹配 v2.4 开始采用的重开确认；失败记录保留，修正的是夹具输入，游戏的确认语义不变。

运行命令和逐项结果见仓库证据与发布说明。原始本机报告位于独立版本目录，早期失败报告不会覆盖为成功。
