# Aegis Arena v2.0 · PRISM FALL 交付说明

面向系统／综合策划的原生 Unreal C++ 作品集。美术方向为科幻遗迹与生长晶体；新增蓄能射击、中继超频、按实际治疗量计费的修复、路线选择和中继共生升级。共享能量连接输出、保护与任务推进，便于演示系统取舍。

## 直接启动

本机桌面双击 **Aegis Arena v2.0**。Enter 开始；WASD 移动、鼠标瞄准、左键射击；退出时 **Esc 打开菜单，再按 X**。结算页可直接按 X 退出。启动器固定种子 1101，与正式视频使用的场景种子一致；R 同种子重开。玩家可自行选择路线与升级，结果不保证与视频相同。

完整游戏已安装到 `D:/AegisWork/Playable/Aegis-Arena-v2.0`。也可双击其中的 `Start-Aegis-Arena-v2.bat`，无需 Unreal 编辑器或 API Key。换电脑时，解压交付目录中的 `Aegis-Arena-v2.0-Windows.zip` 整个目录后运行启动器，不要单独移动 EXE；运行库位于包内 `Engine/Extras/Redist/en-us`。

| 输入 | 实际规则 |
|---|---|
| 右键按住 0.7 秒再松开 | 蓄能弹；成功发射才消耗 12 能量 |
| Space | 冲刺 |
| Q | 消耗 35 能量解围 |
| E | 修复自己及范围内可支援的队友；按实际治疗量报价 8–40 能量，无合法治疗不扣费 |
| F | 前两阶段当前中继圈内消耗 35 能量，6 秒内推进速度 ×2；争夺期间仍消耗超频时间 |
| V | 简报或第一次升级时选择第二阶段先北或先东 |
| 1／2／3 | 升级页选择一项升级 |
| Z／X／C | 跟随掩护／集火／向鼠标位置集结 |
| F1 | 独立开关决策诊断面板 |
| Esc／P | 暂停菜单；菜单 X 退出；R 重开 |

任务依次为：占领中继并清敌 → 连接两个中继并清敌 → 清敌后玩家进入撤离圈。

另一个桌面入口 **Aegis Arena v2.0 Decision Lab** 打开独立决策实验室，可观察实际 Utility 与 EQS。PRISM FALL 的战术分支使用 BT 调度，但不由 Utility 分数选择动作，也不运行 EQS 选位；F1 会明确显示这一差别。实验室不与 v2 战术评测混为同一策略。

## 真实演示与验证范围

视频中游戏区域来自最终包的一次连续原生运行：3656 张原始截图，没有插入生成的游戏画面。玩家由普通按键脚本驱动，敌人与队友使用实际游戏逻辑；没有人为注入伤害。音效依据引擎真实触发事件混音，并非系统回环录音。演示完成 3/3 阶段，用时 106.8 游戏秒，团队输出 1260，玩家／队友承伤 238／42，队友存活。视频时长另含简报、升级、结算和说明片头片尾，不能当作通关计时。

最终包通过 36 项受控操作检查、35 项实验室输入检查。Guard 前后两次受控机制检查各 12 项：旧策略复现遮挡位置不射击，新策略只增加候选站位的射线可达检查后完成一次真实射击。固定目标、伤害关闭的局部实验不证明整体输出更高。

开发场景校准并冻结源码、内容与包体后，三个新种子各运行 legacy／improved 两次。六局均完成任务，队友均存活；结果有明确代价：5501 队友输出 98→136，但耗时增加 10 秒、玩家承伤增加 14；6607 报告指标一致；7703 队友输出 84→108，但玩家／队友承伤增加 104／42。动作状态切换包括瞄准、开火、移动，次数降低不等于策略更好。

旧的 1280×720 六局评测完整保留，其中两个种子双策略卡角失败。该批次与开发场景 1920×1080 不一致，不能与最终批次混合汇总，也不能据此认定分辨率导致卡角。录制器的空路径撤离故障与修复另见[录制工具案例](portfolio-v2-recording-case.md)；旧卡角限制仍未修复。

没有强化学习训练、真人试玩统计或普遍胜率提升声明。v1.3 的云端 Copilot 作为历史可选技术说明保留，没有参与本轮 v2 视频或评测。
