# Aegis Arena v1.2 · Uplink

这轮直接回应真人试玩反馈：原来的三波主要重复清敌；队友容易失联或挡枪；敌人站定对射；退出没有清楚入口。参考与获奖来源见 [Hades、Into the Breach、Deep Rock Galactic](upgrade-v3-references.md)。以下是适配本作的设计，不代表复刻这些游戏或达到其完成度。

## 如何退出与操作

**Esc 随时打开游戏菜单；菜单有继续、重开、退出桌面三个可点击按钮。菜单中按 X 也会退出。** 开场和结算页直接显示退出桌面按钮。战斗中的 X 是集火命令，不会退出。

| 输入 | 动作 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 鼠标 / 按住左键 / 右键 | 瞄准 / 连射 / 近战 |
| Space | 有碰撞的方向闪避；没有无敌帧 |
| Q | 420 cm 脉冲，32 伤害，击退并打断预警，基础冷却 6 秒；墙会挡住效果 |
| Z | Guard：回到玩家侧后方、避开玩家枪线、掩护与近距治疗 |
| X | Focus：在准星附近标记可见敌人；队友仍需自己的有效视野和通畅射线才能开火 |
| C | Rally：在鼠标指向的可达地面守点，可让队友单独操作中继 |
| 1 / 2 | 开场选 Guided / Pressure |
| 1 / 2 / 3 | 局间选一项未拥有的升级 |
| Enter / R | 开始 / 返回全新简报 |
| Esc / P | 菜单与继续；升级选择尚未完成时，关闭菜单仍保持升级暂停 |

## 目标与选择

三阶段仍共享 180 秒时限，但目标改变：第一阶段操作一个中继并清敌；第二阶段顺序操作两个相隔的中继并清敌；第三阶段清除精英与剩余敌人，然后由玩家进入撤离圈。第一、二阶段可由队友独自占点，第三阶段必须玩家到场。

圈内无敌人时开始充能，单人速率 1，双人速率 1.5。敌人争夺或无人占领会冻结进度；不会静默倒扣。前两阶段每个中继需要 4 秒基础充能，撤离需要 3 秒。Guided 每波 3 / 4 / 5 名敌人，Pressure 4 / 5 / 6，包含不同角色；最后一波有精英。

前两阶段结束后时间暂停，让玩家从三种升级中选一项，再进入 5 秒恢复与移动时间。升级只保留到本次尝试结束，已拥有的升级不能重复选择：

- **Piercing Rounds**：一发弹最多击中两名敌人，便于利用敌人的站位；掩体与友军仍阻断弹道，同一目标不会重复受伤。
- **Rescue Pulse**：Q 除原有作用外，自疗 12，并治疗有通畅视线且在范围内的活同伴 20；不能复活。
- **Life Link**：真实生效的队伍伤害按 10% 修复玩家与同伴的生命；不靠面板伤害或打空气触发，也不复活。

## 队友与敌人

队友通过明确的队伍位置链路保持协作，不再必须“看到玩家”才知道如何跟随。Guard 使用侧后方阵位与枪线避让，Rally 在命令点附近活动，Focus 的目标身份与授权射击条件分开。HUD 显示控制器当前战术状态，并为指令提供确认或不可执行原因。

敌人有 Striker、Flanker、Suppressor 三种形态与战术距离。它们会向已知任务区域推进，接敌后选择完整 NavMesh 路径来换位，射击后再次移动。没有有效敌方视野时，只使用获准保留的旧位置或固定任务点，不读取玩家实时位置来穿墙追踪。

默认伤害的自动观察额外暴露了一个实际启动缺陷：感知组件早于控制器附身注册，把已经在场的玩家与同伴按 Neutral 排除；UE 的队伍赋值不会自动刷新这些查询。现在在附身、队伍初始化后刷新监听器。旧定向场景的感知开关曾掩盖这个问题，因此新增三条按真实出生顺序、不给该敌人切换感知的回归。失败观察与修复后的记录均保留。

敌人开火前显示固定瞄准点的预警，三种角色分别约 0.6 / 0.7 / 0.9 秒。发射时仍检查遮挡和友军；预警期间不把标记贴着玩家移动。玩家可闪避射线或用脉冲打断。场景中的预警与脉冲环在 Shipping 同样可见。
