# Aegis Arena v2.1 精简证据索引

本目录保存 19 份原始 JSON 的逐字节副本，以及 `sources.json` 来源登记。每条记录包含原件绝对路径、SHA-256、大小、复制相对路径和验证范围。副本保留原始字段与绝对路径，没有改写原报告或把失败改为通过。

最终运行源码为 `4512e5e07bad285542e35911f7915d0d84beaae134aa7195861d67659343d3ea`。`failures/capture-01` 是修复前快照，不与最终包混为同一源码。此前共享弹道索引越界造成的失败仍保留；最终包无截图回归是技术检查通过、自然任务失败，结算仍记录 Lost。最终连续录像另记录自然 Won，两种结果互不替代。

- `acceptance-final-01.json`：已有最终验收登记的原样副本。本次整理没有重新生成或扩大验收结论。
- `control/`、`audio/`、`decision-lab/`：分别保留 36、15、35 项原生检查记录。控制夹具与输入检查不能作为真人体验、自然战斗胜率或 AI 泛化证据。
- `capture/`：最终普通脚本输入的连续包体录像出处与真实结算，没有受控夹具伤害；`regression/` 保留自然失败回归。
- `video/`：编码、完整解码、来源绑定与代理逐图检查记录；`document/` 保存文档构建与代理逐页视觉检查记录。
- `vfx-final-01.json`：玩家真实射击与撞击计数、27 组件预算及峰值等记录；不等于全场景视觉质量或 GPU 帧率测试。

录像的声音按引擎实际记录的资产、时间、增益、音高和淡化事件离线重混，并非声卡原声回录。独立 `audio/` 检查保存 UE Master Submix 播放、静音、恢复的真实 PCM 测量出处；该检查披露离屏音量与持续生成静音缓冲的测试覆盖设置，只覆盖这些片段，不证明七首音乐全部完成声学实录，也不证明物理扬声器或真人听感。

历史 v2.0 Guard 与评测保留在其原始证据和文档引用中，不冒充 v2.1 重新进行的策略比较。本轮没有强化学习训练，也没有基于录像成功声称整体 AI 提升。

此目录刻意不复制全部 PNG、巨大 `capture.json`、视频、音频、可执行文件、包体容器或完整事件轨迹；这些原件继续位于各报告登记的位置。哈希核验副本不代表可在移除外部原件后独立重放全部验收。`delivery/` 收录新附件清单、可玩目录逐文件复制验证、旧 v1.5／v2.0 附件删除前清单及删除后不存在确认；历史失败原件继续保留。
